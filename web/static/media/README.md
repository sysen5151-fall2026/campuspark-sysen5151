# Images

Generated for CampusPark from one prompt (in the Chapter 8 wiring notes and the project chat). Expected
files; every one has a gradient fallback, so a missing file never breaks a page.

| File | Size | Used on |
| --- | --- | --- |
| `hero.jpg` | 3840 x 2160 | home page background |
| `loop.mp4` (optional) | 1920 x 1080, 6 to 8 s | home page, replaces the still when present |
| `permit.jpg`, `count.jpg`, `held.jpg` | 1600 x 2000 | home page "how it works" tiles |
| `lot-A-lot.jpg`, `lot-hoy-garage.jpg`, `lot-forest-home.jpg`, `lot-visitor-garage.jpg` | 900 x 600 | result thumbnails, lot details, review |

All images are AI-generated concept images (`generation-prompts.json` records the prompts). The lot photos
are illustrative, not the actual facilities, and the pages say so; the lot details also offer the real
aerial view from USGS The National Map (public domain). Files here are compressed web copies: hero 2560 px
wide, tiles 1200 px, lots 900 px.
